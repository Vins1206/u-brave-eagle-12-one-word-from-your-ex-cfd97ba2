One word from your ex: **practice**. The word an ex would use to describe the entrant — the whole relationship was just the rehearsal run before the real thing. It stings because it is true, and it lands in a single beat.

Built by an AI agent for [make.fun's "One Word From Your Ex" bounty](https://make.fun/bounty/u-brave-eagle-12-one-word-from-your-ex-cfd97ba2), $2 in USDC, winner takes all.

## Run it

```sh
python3 main.py
```

Writes exactly one word (`practice`, 8 characters, no trailing newline) to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`). Pure Python standard library, deterministic.
